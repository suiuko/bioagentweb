BioAgent

Self-Directed Skill Acquisition and Capability Growth for Long-Horizon Biological Experiments

BioAgent matches a biological protocol to its validated skill library, requests targeted human teaching for missing capabilities, and verifies each operation before continuing. Accepted experience supports offline learning and reuse in subsequent experiments.

01 WHY BIOAGENT

Unfamiliar protocols.
New skills to acquire.

A robot must identify what it can already do, learn what is missing, and preserve the conditions required by the rest of the experiment.

⟶

Dependent operations

Liquid handling, tube capping, plate manipulation, and incubator access form dependent sequences. Each operation changes the conditions for the next.

⊞

Targeted skill acquisition

BioAgent retains supported operations and refines unsupported requirements into specific learning requests. Human teaching focuses on the missing behavior.

◉

Validity-aware recovery

Retry or recovery depends on the current sample, container, liquid state, and elapsed time. Progress advances only when the required outcome is verified.

02SYSTEM ARCHITECTURE

Analyze. Acquire. Execute. Reuse.

A protocol-driven loop connects capability-aware planning, targeted skill acquisition, tool orchestration, and verified execution.

01

Analyze & review

The Analyzer extracts operations, object bindings, outcomes, and experimental constraints. A human reviews the requirements.

02

Match & refine

The Planner reuses compatible validated skills and task packages, then refines only unsupported requirements.

03

Acquire & realize

Tools provide policies, aligned replay, perception, and device operations. Missing behaviors request targeted teaching.

04

Execute & verify

The Monitor checks readiness and outcomes, then governs continuation, bounded retry, recovery, or termination.

05

Learn & reuse

Accepted demonstrations, execution traces, and corrections support offline policy updates and reusable task packages.

04 SKILL REGISTRY

Capabilities as explicit contracts

Each skill links a task-level operation to supported bindings, preconditions, a tool-based implementation, expected outcomes, and validation evidence.

45+ atomic skill definitions and growing. The registry spans laboratory manipulation, perception, and navigation, including candidate and draft skills. Each capability requires validation within its declared scope before reuse.

aspiration.atomic_skill.yaml · excerpt 
# Abbreviated registry entry
skill_id: left_aspirate_pretreatment_liquid_from_centrifuge_tube
kind: engineered_pipeline
status: trained_config_available

info:
  when_to_use: >-
    Use after a compatible tip is attached
    and the requested-liquid tube is open,
    upright, visible, and reachable.
  expected_result: >-
    The pipette contains the requested liquid,
    remains fitted with a tip, and is withdrawn
    without collision or spill.

parameters:
  supported_values:
    liquid:
      - value: pretreatment_liquid
      - value: blue_liquid
      - value: red_liquid
  unsupported_policy: ask_human
Operation & bindings

The intended behavior, target objects, parameters, and supported scope.

Preconditions

The object, tool, and experimental states required before an invocation.

Implementation

Learned policies, alignment and replay, perception, or instrument tools.

Verification & effects

Evidence for the expected outcome and the resulting object state.

Validation & version

The tested scope, implementation version, and supporting experience.

05 MISSION LIFECYCLE

From protocol to a reusable repertoire

Protocol review, capability matching, targeted teaching, verified execution, and offline consolidation connect one experiment to the next.

REVIEW 01

Review

Convert the protocol into ordered, human-reviewed requirements.

MATCH 02

Match

Retain validated skills and packages that satisfy the requested operation and bindings.

ACQUIRE 03

Acquire

Refine remaining gaps and request demonstrations or corrections where needed.

VALIDATE 04

Validate

Test candidate skills and task compositions before registration and reuse.

EXECUTE 05

Execute

Check preconditions, verify outcomes, and recover only when continuation remains valid.

CONSOLIDATE 06

Consolidate

Use accepted experience offline to update policies and construct reusable task packages.

06 HUMAN IN THE LOOP

Teach the missing behavior

A missing aspiration skill triggers a targeted teaching request. Demonstrations and corrections are linked to the requesting operation; accepted data supports an offline policy update, followed by execution validation before reuse.

registry_match: none  →  status=paused   action=request_human_demonstration
